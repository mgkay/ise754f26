# OpenStreetMap road data

`osm_w-78.7_e-78.6_s35.75_n35.85_nodes.csv` and `osm_w-78.7_e-78.6_s35.75_n35.85_links.csv` are the drivable roads of a part of
Raleigh, North Carolina, extracted from OpenStreetMap.

**© OpenStreetMap contributors.** The data are available under the Open Database
License (ODbL), <https://opendatacommons.org/licenses/odbl/>; see
<https://www.openstreetmap.org/copyright>. These two files are a database derived from
OpenStreetMap and are distributed under the ODbL.

- Bounding box requested: longitude -78.7 to -78.605, latitude 35.75 to 35.82;
  `osm_roads` widens it to the 0.05° grid, so the box returned covers longitude -78.7
  to -78.6, latitude 35.75 to 35.85.
- Downloaded from the Overpass API on 2026-10-12, through Logjam's `osm_roads`.
- 45218 nodes and 82497 links.
- Regenerated by `julia --project=. 4-networks/source/make_osm_raleigh.jl`, which keeps
  this pair and fetches again only when it is missing.

`geocode_cache.csv` holds the longitude and latitude Nominatim, the OpenStreetMap
geocoder, returned for two NC State University street addresses on 2026-10-12, in the
form Logjam's `loc2lonlat` reads.
